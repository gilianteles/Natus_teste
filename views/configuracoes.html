Quais botões cada perfil enxerga

Defina os itens da barra lateral exibidos para cada perfil de acesso. Este ajuste é apenas visual: a segurança das rotas permanece validada no servidor.

Personalização de experiência (UX). Ocultar um botão esconde apenas o atalho do menu — as permissões de acesso às telas e às funções continuam sendo verificadas no servidor (lib/auth.js e guardas de tela). O perfil Administrador é fixo, para que esta própria tela nunca saia do menu.

Matriz de visibilidade do menu

Cada coluna é um perfil de acesso; cada linha, um botão do menu lateral. Marque para exibir, desmarque para ocultar.
